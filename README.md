# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子，并标注光照类型（高照/低照）。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 并联等效曲线折算

顶栏「等效曲线」专页把**两笔以上已办结**扫描拖进折算筐，拖条调权重后点「折算并入队」：

- 少于两笔、拖入未办结单据、同一笔重复拖入、权重为负或全零 —— 一律拒收（HTTP 400）。
- 高照与低照两类不能混选，折算筐只接受同一光照类型。
- 等效开路电压、短路电流、填充因子按归一化权重加权；折算成功的新单填充因子即本次加权值。
- 新单只入队，状态保持 `pending`（等候处理），不写结论、不直接标成已办结，由工人按同一规则判定。
- 等效新单、折算流水头（`iv_folds`）、来源明细（`iv_fold_sources`）在**同一事务**入账，缺一边整笔回滚。
- 只读账号 watcher 可打开专页查看实时预览，但看不到可用的折算动作——折算接口对其返回 403。

接口：

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/folds/preview` | 登录 | 按 ids + weights 返回加权等效曲线（不出账） |
| POST | `/api/folds` | 扫描员 | 折算并同事务落账，返回入队新单 |
| GET | `/api/folds` | 登录 | 折算流水及来源权重 |

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 种子

| 组串 | 光照 | 填充因子 | 结论 |
|------|------|----------|------|
| 阵列A-串03 | 高照 | 0.78 | 合格 |
| 阵列A-串07 | 高照 | 0.76 | 合格 |
| 阵列B-串11 | 低照 | 0.61 | 衰减 |

前两笔高照合格可直接组成一次并联折算；低照仅一笔，凑不足两笔，也不能与高照混选。
